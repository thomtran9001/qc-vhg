# VHG QC — Quality Control Center (mockup)

App quản lý kiểm soát chất lượng cho VHG Living Furniture: PO đồng bộ từ Base, Lead QC lập kế hoạch 5 loại đánh giá (11A–11E), QC kiểm tại xưởng (kể cả offline), duyệt, cảnh báo Critical, chốt PO và xuất báo cáo đúng mẫu.

- Mở app: `Tài liệu KH gửi/vhg-qc.html` (một file, chạy trực tiếp trên trình duyệt).
- Mã nguồn: `Tài liệu KH gửi/src/` — build bằng `node build.js` (chạy trong thư mục `src`).
- Vai trò: Admin · Lead QC · QC. Giao diện Tiếng Việt / English.
- `huong-dan-anh/`: ảnh chụp màn hình dùng cho tài liệu hướng dẫn.
- `index.html` ở gốc: bản mockup cũ (10/2026), không còn dùng.
